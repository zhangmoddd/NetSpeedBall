# 网络测速球

一个轻量 Windows 网络测速小工具。它用原生 WinForms 编写，不依赖 Electron，构建后是单个 `NetSpeedBall.exe`。

## 功能

- 悬浮测速球实时显示下载和上传速度
- 单击悬浮球可查看 CPU、内存、磁盘占用及网络详情
- 详情面板显示今日/本月下载与上传流量，重启不清零，只有过了 00:00 才算新的一天
- 流量统计窗口：按天/月/年或任意日期范围查看总流量与日均流量，附每日流量柱状图和应用流量排行榜
- 白色仪表盘悬浮球带云层和小火箭，火箭会持续绕圈，低速慢转、高速快转，下载速度超过 500KB/s 时显示尾焰
- 按住悬浮球会出现发射台，拖入后松手可触发纯动画火箭发射互动
- 系统托盘常驻，右键可以显示/隐藏悬浮球、切换置顶、切换开机自启动、退出
- 右键菜单可直接打开 Windows 任务管理器
- 鼠标左键拖动悬浮球，松开后自动保持在屏幕工作区内
- 拖到屏幕边缘松开可贴边收起，鼠标移入后自动展开
- 双击悬浮球可临时切换置顶状态
- 使用当前用户注册表启动项实现开机自启动，不需要管理员权限
- 已声明系统级 DPI 感知，高分屏（125%/150% 缩放）下悬浮球与文字渲染清晰

## 流量统计说明

- 总流量（今日/本月/日均/柱状图）：按网卡层真实字节增量统计，含所有协议
- 应用排行榜：通过每条 TCP 连接的字节计数器归因到进程（与资源监视器同机制，不需要管理员权限）；不含 UDP/QUIC 流量与协议头开销，因此各项之和略小于总流量
- VPN/代理：检测到隧道类网卡（TUN/PPP，含 WireGuard）在线时只统计隧道流量，避免与物理网卡重复计数
- 数据保存：`%LOCALAPPDATA%\NetSpeedBall` 下两个小文件（归档 + 增量日志），重度使用一年不足 1 MB；每 60 秒落盘一次，退出时归档，重置今日流量只在托盘菜单触发

## 构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

生成文件：

```text
dist\NetSpeedBall.exe
```

## 使用

直接运行 `dist\NetSpeedBall.exe`。托盘图标右键菜单里可以开启“开机自启动”、打开“流量统计”，也可以随时退出。

## 轻量说明

程序按实际计数器增量计算当前流量速率，并使用短时间平滑减少单秒抖动。统计优先选择带默认网关的物理网卡（VPN 隧道在线时改为只统计隧道），避免代理、VPN 或虚拟网卡把同一流量重复计算；程序没有后台网络请求、没有测速服务器探测，也不会主动制造流量，因此显示的是当前实际网络活动，不是线路带宽上限。
